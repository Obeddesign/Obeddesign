# PMD — Front-end

Application front-end développée avec **Angular 17** et **TypeScript** dans le cadre d'une expérimentation full-stack.

## Objectif

Mettre en pratique une architecture front-end moderne, structurée autour de composants réutilisables, du routage et du rendu côté serveur.

## Stack

- Angular 17
- TypeScript
- SSR
- HTML / CSS

## Lancer le projet

```bash
npm install
ng serve
```

Puis ouvrir : `http://localhost:4200`
